# 交易与合同审查

本模块用于 `deals_contracts` 路由中的报价、订单、合同、补充协议和往来确认审查。中国大陆是默认分析法域和适用法背景，不是对实际适用法律或争议解决地的预设；应从当事人、履行、合同和交易连接因素识别适用法律、法院或仲裁机构。出现境外主体、境外付款、香港、外国法或跨境数据时，按 `jurisdiction-source-policy.md` 标示“跨境”并评估是否交接律师。

## 审查方式

先确认文件版本、交易背景、拟签署主体和业务目标；一次只追问一个会实质改变结论的事实。将已核实事实与假设分开。适用规则或资料需要研究时标记来源状态为 `needs_verification`；无法可靠核验时标记 `unavailable`，不得以臆测或虚构引文补足。

每项合同问题以以下记录返回，字段不得省略：

```json
{
  "location": "第[条款号]条/[标题]",
  "risk": "low | medium | high",
  "reason": "事实、条款效果和不确定性",
  "recommendation": "可执行的谈判或补充动作",
  "replacement_text": "可直接替换或新增的条款草案"
}
```

`replacement_text` 是需结合交易填充和确认的草案，不是签署指令或正式法律意见。问题按风险由高到低排序，并说明重要假设、资料缺口和是否需要 `lawyer_handoff`。

## 必审清单

### 1. 主体、授权与签署

- 核对双方主体全称、统一社会信用代码或其他识别信息、注册地址、通知地址和收款账户是否一致。
- 确认签署人职务、授权链、盖章安排和是否需要关联方、客户或分包商加入。主体不明、无授权或代签风险通常至少为 `medium`。

### 2. 范围、交付、变更与验收

- 将服务范围、明确排除项、客户配合义务、前置依赖、交付物、格式、里程碑和交付方式写成可验证的事项。
- 约定变更提出、评估、报价、书面批准、追加费用和工期顺延机制；单方变更范围应视为推定 `medium` 或 `high` 风险。
- 约定验收标准、验收期限、缺陷清单、补救期限、逾期未反馈的处理以及不影响已验收部分付款的规则。付款以对方主观满意为条件，应视为推定 `medium` 或 `high` 风险。

### 3. 价格、税务、发票与付款

- 明确含税或未税价格、税率口径、币种、报价有效期、费用报销、发票类型和开具条件。
- 明确订金、阶段款、尾款、付款日期、付款账户、付款前提和逾期付款后果。
- 审查暂停服务权、恢复条件及暂停造成的工期影响；不得把开票、验收或付款先后关系留作推定。逾期付款可设置经书面提醒后的暂停服务和合理的违约后果，但应与交易相称。

### 4. 知识产权与客户材料

分别列明并避免混同：

- 背景知识产权：签约前已有的代码、方法、素材、品牌、工具和权利；
- 客户材料：客户提供或指定使用的资料、数据、商标和内容；
- 项目交付物：为本项目约定交付的成果及其权利范围；
- 工具、模型与可复用诀窍：通用模板、组件、工作流、模型配置、提示词方法、经验和改进。

明确客户材料由谁保证授权；背景知识产权、工具、模型和可复用诀窍归原权利人，必要时仅按项目目的授予使用许可。要求永久、笼统、无边界地转让全部知识产权，特别是包含既有工具或未来改进时，应视为推定 `medium` 或 `high` 风险。

### 5. 其他关键条款

审查保密、个人信息、模型使用、分包、陈述保证、赔偿、责任限制、期限、终止、适用法律和争议解决。至少确认：

- 保密信息、例外、允许披露对象、保密期限及返还或删除安排；
- 是否处理个人信息、是否可使用模型、是否需取得客户书面授权，以及分包或供应商的约束；
- 保证和赔偿的触发条件、程序、排除事项及责任上限；
- 责任限制是否包括间接损失、利润损失和可保或不可保的项目。无限责任通常为推定 `high` 风险；
- 期限、续期、解除事由、补救期限、终止后交接、已完成工作和费用结算；
- 从交易事实和合同约定识别适用法律、争议解决机构或法院、仲裁地、送达地址和执行安排。涉及外国法、香港或其他跨境安排，标记“跨境”并按风险政策处理。

## 可调用模板与加载条件

模板仅在当前任务需要相应文书时加载，不能因进入本模块而全部加载：

- 报价、范围、付款或签约前确认需要书面固化时，读取 `templates/quotation-confirmation.md`。
- 双方需要单独约定信息交换与保密边界时，读取 `templates/nda.md`。
- 需要起草或重构完整服务交易条款时，读取 `templates/service-agreement.md`。

## 常用问题草案方向

以下仅用于将审查建议转为可谈判文本，方括号须按交易填充。

- **单方范围变更**：`任何范围、交付物、客户配合、费用或进度的变更，须经双方书面确认其影响后生效；未确认前，服务方按原约定继续履行。`
- **主观验收付款**：`客户应依据本协议约定的验收标准在[验收期限]内提出具体书面缺陷；逾期未提出的，视为该阶段交付物已验收。已验收或视为验收的部分应按约定付款。`
- **责任限制**：`除因一方故意或依法不得限制的责任外，任一方就本协议承担的累计赔偿责任以客户在引发索赔事项前[十二]个月已支付的服务费总额为限。`
- **保留背景权利**：`服务方的背景知识产权、工具、模型、通用组件、方法论及可复用诀窍均归服务方所有；客户仅在支付对应费用后，为使用项目交付物之目的获得必要的非排他使用权。`

草案不能替代对交易事实、法律来源和签约权限的核验。
