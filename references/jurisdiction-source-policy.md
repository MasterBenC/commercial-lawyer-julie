# 分析法域与来源政策

## 适用法背景与争议解决判断

中国大陆是第一版的默认分析法域和适用法背景，但这不是对任何交易的适用法律、法院或仲裁地的预设。应根据当事人所在地、履行地、合同中的适用法律与争议解决条款、交易结构和其他连接因素识别并核验实际安排。

只要问题涉及香港、外国法、境外主体、境外付款或跨境数据，就必须在输出中显示“跨境”标记，并按需要触发 `complex_cross_border_matter` 的 `lawyer_handoff` 原因。不得把中国大陆法律当然延伸适用于香港、外国法或其他法域；应说明待确认的适用法律、法院、仲裁机构、仲裁地、送达和执行安排。

## 法律来源与核验

对可能变化的法律、行政法规、部门规章、司法解释、监管规则或执法口径，必须以权威的一手来源核验。每项已使用的来源应记录：

- 标题；
- 制定或发布机关及公布文号（如有）；
- 发布日期和生效日期（如可获得）；
- URL；
- 核验日期；
- 来源状态。

来源状态只能使用以下值：

- `kb`：已从已挂载的 personal-kb 对应文件读出（内部分析可用；对外正式用途或中高风险依赖条文时仍应升级核验）；
- `verified`：已通过权威一手来源核验；
- `needs_verification`：需要进一步检索或核验；
- `unavailable`：核验失败或无法取得可靠来源。

绝不得为了让回答看起来完整而编造引文。研究尚未完成时使用 `needs_verification`；核验失败时使用 `unavailable`，并明确说明限制。

## 本地知识库优先检索

当宿主已挂载 `personal-kb`（见 `references/kb-mount.md`）时，对中国大陆民商法与税法中已入库的黑字文本，应把该库作为**第一轮检索语料**：先读 `_index.md`，再只打开 `01-民商法/`、`02-税务/` 或 `03-交汇专题/` 中与争点相关的路径。知识库命中可在输出中引为相对路径，来源状态记为 `kb`；这不等于完成权威核验。

对外部正式用途，或风险为 `medium` / `high` 且结论依赖具体条文时，仍须以权威的一手来源核验，并将状态升级为 `verified`（记录标题、发布机关、生效日期、URL、核验日期）。库未挂载、文件缺失或文本可疑时使用 `needs_verification` 或 `unavailable`，绝不得为了让回答看起来完整而编造引文。

本地知识库不能单独证明合同的适用法律、管辖法院或仲裁机构；适用法与争议解决仍须按上文从交易连接因素识别。不得默认加载 `05-客户案例-脱敏/`。可选的 `miit-qualification-kb` 仅在用户明确询问高新、专精特新、单项冠军或申报时使用，且同样不能替代一手核验。
