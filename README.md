# 商业律师 Julie

商业律师 Julie 是面向以中国大陆业务为主的 AI 一人公司（AI OPC）的商业法律风险辅助 Skill。它帮助经营者在接洽、报价、签约、履约、变更、验收、收款和争议处理的业务生命周期中，识别下一步需要确认的事实、风险和材料。

## 能做什么

Julie 支持三种可切换的工作模式：

- **快速问答**：回答当前业务决策中的聚焦问题。
- **材料审查**：审查合同、报价单、工作说明、沟通记录或证据材料。
- **流程陪跑**：根据交易所处阶段给出下一步的法律与商业行动建议。

它还覆盖交易与合同、AI 数据与知识产权、履约变更验收、开票收款、争议证据和律师交接等模块。输出是风险辅助与文本草案，不会自动向外发送、签署、付款或提交任何材料。

## 示例

> 我为客户制作 AI 内容服务，客户要求将全部提示词和模型工作流永久转让；报价已确认但尚未签约。请审查风险并给我下一步沟通要点。

Julie 会按“报价 / 签约”阶段检查权利边界、交付物范围、付款条件、客户素材和模型使用安排；若涉及境外主体、外国法、香港、境外付款或跨境数据，会标记为“跨境”并建议进一步核验或律师交接。

## 安装

将本目录 `commercial-lawyer-julie` 复制或克隆到宿主应用的 Skill 目录，然后在宿主中启用或调用 `commercial-lawyer-julie`。例如：

```text
<host-skill-directory>/commercial-lawyer-julie/
```

安装后，宿主会读取 `SKILL.md` 并按其中的路由加载相应参考资料和模板。本包不要求运行时依赖或外部服务。

## 本地验证

需要 Node.js 20 或更高版本：

```bash
npm test
npm run validate
npm run eval:prepare
npm run eval:render
npm run eval:manifest
```

`npm test` 运行完整的静态结构、政策内容和场景夹具测试套件；`npm run validate` 检查发布所需文件，并机械校验已提交的 metadata schema、18-run index 和评测报告合计；其余命令分别生成 prompt-only 输入、隔离运行时和 18-run manifest。这组标准命令可在不含 gitignored `work/` 原始运行记录的干净发布包（clean release archive）中执行。静态检查与资产生成不等于完整行为验收。v0.1.0 已按 [风险分层独立评测报告](evaluations/2026-08-02-risk-tiered-evaluation.md) 完成 18/18 行为 PASS、14/14 场景和 4/4 重复关键场景通过；证据有效性仅在披露的指令约束隔离标准下成立，未证明 OS 级隔离。

### 评测控制器专用

仅当控制器工作区中的 `work/risk-tiered-evaluation/runs/` 原始 run artifact 全部存在时，才运行：

```bash
npm run eval:validate-runs
```

该命令在评分前重新解析 raw run metadata、核对 manifest 并生成规范化 index；它不是干净发布包的标准本地验证命令。原始回答仍留在 gitignored controller work 目录，不会被复制进发布包。

## 法域、安全与隐私边界

- 中国大陆是默认分析法域和适用法背景，不是对合同适用法律、法院或仲裁地的预设。涉及香港、外国法、境外主体、境外付款或跨境数据时，必须标记“跨境”，从交易事实核验实际安排，并在需要时交接持证律师。
- 不构成律师委托，不替代持证律师正式法律意见、出庭服务或特定结果保证。
- 仅提供完成当前分析所需的事实；上传前请遮盖无关的身份证号码、银行卡号、访问令牌、密钥及其他敏感信息。
- 提交给宿主或模型服务的内容可能依宿主、模型、插件、日志和工具配置而传输或保留。请先核对所用服务的数据处理与保留设置；本地运行也不等于绝不发生外部传输。
- Julie 不协助伪造、篡改、隐匿或销毁证据。
